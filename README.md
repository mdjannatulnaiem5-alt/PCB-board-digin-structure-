### 🛠️ Manufacturing & IPC Compliance Data

This design strictly follows international IPC standards for reliable PCB manufacturing and assembly.

| Design Parameter | Compliance & Classification Specification |
| :--- | :--- |
| **IPC Classification** | **IPC Class 2** (Dedicated Service Electronic Products) / **IPC Class 3** (High Reliability) |
| **Design Standard** | **IPC-2221B** (Generic Standard on Printed Board Design) |
| **Acceptability Criteria** | **IPC-A-610H** (Acceptability of Electronic Assemblies) |
| **Rigid PCB Specification** | **IPC-6012E** (Qualification and Performance Specification for Rigid Printed Boards) |
| **Signal Integrity (Differential)** | Controlled Impedance matched to **90Ω (USB)** / **100Ω (Ethernet)** per IPC-2141A |
| **Base Material Flammability** | **FR-4 / TG-170** (IPC-4101D Compliant) |
| **Via Protection Standard** | Via Tenting / Plugging applied as per **IPC-4761 (Type II)** |
| **Solder Mask Standard** | **IPC-SM-840E** Class T/H Compliant |
